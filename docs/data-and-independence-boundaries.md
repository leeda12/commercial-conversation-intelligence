# Data and project-independence boundaries

The demonstration is restricted to original fictional content created for this repository. All organizations, people, products, conversations, events, dates, amounts, and CRM records are invented. Fictional email addresses use `example.com`.

The interface does not accept free-text transcripts or file uploads. It provides no persistence, accounts, analytics, tracking, external integrations, or background actions. JSON, CSV, and text exports are generated locally in the browser.

Simulated confidence values are editorial signals in a precomputed demonstration. They are not live model probabilities and are labelled accordingly.

Repository material must not include real workplace information, customer information, proprietary schemas, internal screenshots, private URLs, credentials, or descriptions derived from third-party systems.
